# Muscle Pal model placeholders

Four original image assets for future onboarding/settings model selection and profile avatars:

- `male-full-body.png`: complete male figure, transparent background.
- `female-full-body.png`: complete female figure, transparent background.
- `male-profile.png`: matching male head-and-shoulders portrait, transparent background.
- `female-profile.png`: matching female head-and-shoulders portrait, transparent background.

Art direction: premium semi-realistic 3D athletic characters with natural faces, relaxed poses, charcoal technical sportswear, and restrained electric lime `#C8FA3C` details. Full-body figures have clear space around hands and shoes. Profile portraits are dedicated compositions referencing the corresponding figure for identity consistency, with room for a circular crop.

The subjects are generated adult characters. Generated using the built-in image_gen tool. Exact prompts and original dimensions are in `manifest.json`. `preview.png` shows the assets composited on the app's charcoal surface for review; individual PNGs retain transparency.

Assets only. Existing content hero renders, components, content manifests, and app behavior have not been modified. The future UI should apply its own selected-state tint, border, checkmark, labels, and circular avatar mask.
