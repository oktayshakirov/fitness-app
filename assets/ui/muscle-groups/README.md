# Muscle group icons — revision 2

17 original transparent PNG icons covering every `muscleIds` entry in `src/content/types.ts`. Filenames match the app IDs. Assets only; no UI integration.

Redesigned with continuous charcoal silhouettes, fine neutral contours, sparse anatomical landmarks, and electric-lime muscle highlights. This replaces the earlier segmented lavender/pink artwork.

The lime accent `#C8FA3C` and charcoal `#323236` come from `src/theme.ts`. The contact sheet uses the app surface `#1A1A1C`. Contours use neutral gray `#A1A1A6` for visibility on dark surfaces. The first original revised chest icon served as the visual anchor for the other 16; the external screenshot was not supplied to the revised generation.

Each PNG retains its generated alpha and resolution. `preview.png` is a labeled review sheet. `manifest.json` records the palette and prompts used with the built-in image_gen tool.
