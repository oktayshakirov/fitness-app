# Muscle Pal — chest logo identity

Original logo concept derived from the app's approved `assets/ui/muscle-groups/chest.png`, simplified into a compact mark with short upper arms, fewer contour lines, and a tapered torso.

- `logo-mark.png`: standalone mark with transparent background.
- `logo-gradient.png`: centered logo on a full-bleed dark graphite gradient with a restrained lime ambient lift.
- `logo-wordmark.png`: horizontal logo with the confirmed app name, Muscle Pal, on a matching dark gradient.

Palette follows the app: electric lime `#C8FA3C`, charcoal `#323236`, and graphite surfaces `#0B0B0C` / `#252528`; neutral gray contours add separation. These are raster concepts generated with the built-in image_gen tool. `manifest.json` records the prompts and intended palette.

Assets only. Existing app icon, splash, adaptive icons, and app configuration have not been replaced.

Chosen direction: chest-only logo with Muscle Pal wordmark. The full-body exploration remains available separately.
