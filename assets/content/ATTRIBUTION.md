# MakeHuman system hair — CC0

Source: https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html
Pack: https://files2.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip

The source page lists the system hair assets as CC0. Original per-file notices
remain intact: explicitly released as CC0 in September 2020, copyright holders
at release Data Collection AB, Joel Palmius and Jonas Hauquier. Asset author:
makehuman_system. Legal contact: Data Collection AB.

CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/legalcode

The pipeline uses short01 for the male and ponytail01 for the female. The assets
are fitted using MPFB's basemesh references; textures and authored silhouettes
are retained. Reference screenshots used during design are style references
only and are not included in these assets.

Pipeline modifications: short01 sides/nape are tapered toward the fitted scalp
with a graded alpha density for a fade. Ponytail01 is recoloured black by a
strand-preserving shader; original mesh/texture files remain intact.

Revision 7 gently feathers low hairline/card ends while keeping the crown opaque,
with softer rough strand highlights. Source textures and meshes remain intact.
