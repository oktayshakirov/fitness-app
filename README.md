# Fitness

Offline-first Expo / TypeScript app for iOS and Android. Product scope: [MVP](docs/MVP.md),
visual system: [Design](docs/DESIGN.md), progress: [Plan](docs/PLAN.md).

## Local development

Node 22.13+; Xcode and an iOS simulator; Android SDK + Java 17 and an emulator.

```sh
npm ci
npm run ios
npm run android
# Once native builds are installed:
npm start
npm run typecheck
npm test
```

Development builds are used, not Expo Go. Native folders are generated by Expo
prebuild and ignored. `eas.json` includes dev, preview and production profiles; no
EAS project, account, hosting, ad service or purchase service has been created.

## Approved offline content

All 30 exercises from v0.1.0 are bundled (male, light background). Only H.264
videos and WebP posters ship. Screens use the typed repository interface in
`src/content/types.ts`. Do not edit generated `bundled.json` / `bundled-assets.ts`.

To reproduce the import (requires Python 3 and ffprobe):

```sh
npm run content:import -- /Users/oktayshakirov/Coding/fitness-releases/v0.1.0
```

The importer checks the pinned archive digest, every archived file digest,
reviewed text and approval fingerprints. Full media attribution is bundled and
visible in Settings. Never edit the rendering repo from this app workspace.
