# Fitness App

Planning repository for a fitness app powered by the approved exercise library in
[fitness-automation](https://github.com/oktayshakirov/fitness-automation).

**Status: planning only.** No application has been scaffolded, no dependencies
installed and no service deployed. Architecture recommendations remain proposed
until discussed with Oktay. Screenshots and feature requirements will follow.

- [Architecture proposal](docs/ARCHITECTURE.md)
- [Content updates and release contract](docs/CONTENT.md)
- [Decisions and implementation sequence](docs/PLAN.md)
- [Approved source release](docs/MEDIA_RELEASE.json)

Recommended direction: Expo + React Native + TypeScript for iOS and Android,
with native video playback of the existing rendered exercise loops. Keep content
releases independent of app releases. Consider a separate public blog later.
